A newspaper front page summing up Thursday 26 November 2026's world news in
one image: 35 stories across 7 regions — Washington proposing new tariffs on
14 trading partners, a fuel tanker fire killing at least 31 in Cairo, Houthi
strikes on Saudi ports and the Ras Tanura refinery, and the rest of the day's
news, every story dated 26 November 2026. The image is drawn with Pillow
(`render.py`); `main.py` copies it to `$MAKEFUN_OUTPUT_DIR/entry.png`.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

To re-render the image from scratch:

```sh
python3 render.py
```
